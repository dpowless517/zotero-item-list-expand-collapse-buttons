# Release v1.0.3 — Zotero Item List Expand/Collapse Buttons

This release renames the plugin to **Zotero Item List Expand/Collapse Buttons**. It retains the two fold/unfold toolbar buttons and the one-level-at-a-time behavior tested in Zotero 10 on Windows.

### What changed

- Plugin display name is now **Zotero Item List Expand/Collapse Buttons**.
- Public-facing README and release naming have been updated.
- The plugin ID, fold/unfold icons, and expand/collapse functionality are unchanged.

### Installation

Download `zotero-item-list-expand-collapse-buttons-v1.0.3.xpi`, then in Zotero choose **Tools → Plugins → gear icon → Install Plugin From File**. Existing users can install this over v1.0.2 without uninstalling it. Restart Zotero if prompted.

### Compatibility

Earlier code and icons were tested working in **Zotero 10 on Windows**. This renamed v1.0.3 package has been statically checked but still needs a live installation test. Other operating systems and Zotero versions are not verified.

This is an unofficial community plugin. It does not edit reference records or transmit library data. Automatic updates are not configured.
